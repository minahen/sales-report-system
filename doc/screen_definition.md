## 1. 画面一覧

| 画面ID | 画面名 | 対象ロール | 概要 |
|--------|--------|------------|------|
| LOGIN | ログイン画面 | 全員 | メールアドレス・パスワードでログイン |
| REPORT-LIST | 日報一覧画面（営業） | 営業 | 自分の日報一覧を確認・作成へ遷移 |
| REPORT-EDIT | 日報作成・編集画面 | 営業 | 日報の作成・編集。訪問記録を複数行入力 |
| REPORT-DETAIL | 日報詳細画面 | 営業・上長 | 日報の内容確認。上長はコメントを入力 |
| MGR-REPORT-LIST | 日報一覧画面（上長） | 上長 | 部下全員の日報一覧を確認 |
| CUSTOMER-LIST | 顧客マスタ一覧 | 管理者・上長 | 顧客の一覧表示・検索 |
| CUSTOMER-EDIT | 顧客マスタ登録・編集 | 管理者 | 顧客情報の登録・編集 |
| SALESPERSON-LIST | 営業マスタ一覧 | 管理者 | 営業担当者の一覧表示 |
| SALESPERSON-EDIT | 営業マスタ登録・編集 | 管理者 | 営業担当者情報の登録・編集 |

## 2. 共通仕様

### 2-1. ロール定義

| ロール | 説明 |
|--------|------|
| 営業 | 日報を作成・提出する担当者 |
| 上長 | 部下の日報を確認しコメントする管理職 |
| 管理者 | マスタ管理を行うシステム管理者（上長を兼ねる場合あり） |

### 2-2. グローバルナビゲーション

ログイン後は全画面に以下のグローバルナビを表示する。

| 項目 | 遷移先 | 表示条件 |
|------|--------|----------|
| 日報（自分） | REPORT-LIST | 営業・上長 |
| 部下の日報 | MGR-REPORT-LIST | 上長のみ |
| 顧客マスタ | CUSTOMER-LIST | 上長・管理者 |
| 営業マスタ | SALESPERSON-LIST | 管理者のみ |
| ログアウト | LOGIN | 全員 |

### 2-3. 日報ステータス定義

| ステータス | 説明 |
|------------|------|
| 下書き | 保存済みだが未提出 |
| 提出済 | 営業が提出完了 |
| 確認済 | 上長が確認・コメント済み |

## 3. ログイン画面 `LOGIN`

### 3-1. 概要

システムへのエントリーポイント。メールアドレスとパスワードで認証する。

### 3-2. 画面レイアウト

```
+----------------------------------------------+
|              営業日報システム                |
|                                              |
|  メールアドレス                              |
|  [ example@example.com              ]        |
|                                              |
|  パスワード                                  |
|  [ ••••••••                         ]        |
|                                              |
|  [         ログイン         ]                |
+----------------------------------------------+
```

### 3-3. 入力項目

| 項目名 | 型 | 必須 | バリデーション |
|--------|----|------|----------------|
| メールアドレス | テキスト | ○ | メール形式チェック |
| パスワード | パスワード | ○ | 8文字以上 |

### 3-4. アクション

| ボタン | 処理 | 遷移先 |
|--------|------|--------|
| ログイン | 認証処理を実行 | 成功：REPORT-LIST（営業）/ MGR-REPORT-LIST（上長） |

### 3-5. エラーメッセージ

| 条件 | メッセージ |
|------|-----------|
| 認証失敗 | メールアドレスまたはパスワードが正しくありません |
| 未入力 | 必須項目を入力してください |

## 4. 日報一覧画面（営業） `REPORT-LIST`

### 4-1. 概要

ログイン中の営業担当者自身の日報一覧を表示する。新規作成・過去日報の参照が可能。

### 4-2. 画面レイアウト

```
+--------------------------------------------------------------+
|  [グローバルナビ]                       田中 太郎 | ログアウト |
+--------------------------------------------------------------+
|  日報一覧                       [＋ 今日の日報を作成]       |
|                                                              |
|  絞り込み: [ステータス ▼]  [年月 ▼]  [検索]               |
+--------------------------------------------------------------+
|  日付       | ステータス | 訪問件数 | 最終更新         |      |
|-------------|------------|----------|------------------|------|
|  2024/11/20 | 確認済     | 3件      | 2024/11/20 18:00 | [表示] |
|  2024/11/19 | 提出済     | 2件      | 2024/11/19 19:30 | [表示] |
|  2024/11/18 | 下書き     | 1件      | 2024/11/18 15:00 | [編集] |
+--------------------------------------------------------------+
```

### 4-3. 表示項目

| 項目名 | 説明 |
|--------|------|
| 日付 | 日報の対象日 |
| ステータス | 下書き / 提出済 / 確認済 |
| 訪問件数 | visit_records のレコード数 |
| 最終更新 | updated_at |

### 4-4. アクション

| ボタン | 処理 | 条件 |
|--------|------|------|
| 今日の日報を作成 | 本日付の日報を新規作成 | 当日の日報が未作成の場合のみ表示 |
| 表示 | REPORT-DETAIL へ遷移 | ステータスが「提出済」「確認済」 |
| 編集 | REPORT-EDIT へ遷移 | ステータスが「下書き」 |

## 5. 日報作成・編集画面 `REPORT-EDIT`

### 5-1. 概要

営業担当者が日報を入力・保存・提出する画面。訪問記録は複数行追加可能。

### 5-2. 画面レイアウト

```
+--------------------------------------------------------------+
|  [グローバルナビ]                                            |
+--------------------------------------------------------------+
|  日報作成  2024年11月20日（水）                              |
|                                                              |
|  ■ 訪問記録                                                 |
|  +----------------------------------------------------------+|
|  |  #  | 顧客名            | 訪問内容            | 訪問時刻 ||
|  |-----|-------------------|---------------------|----------||
|  |  1  | [株式会社A ▼]    | [詳細をここに入力…] | [10:00]  ||
|  |  2  | [株式会社B ▼]    | [詳細をここに入力…] | [14:00]  ||
|  |  ＋ 訪問記録を追加                                       ||
|  +----------------------------------------------------------+|
|                                                              |
|  ■ 今日の課題・相談（Problem）                              |
|  +----------------------------------------------------------+|
|  |                                                          ||
|  |  [テキストエリア]                                        ||
|  |                                                          ||
|  +----------------------------------------------------------+|
|                                                              |
|  ■ 明日やること（Plan）                                     |
|  +----------------------------------------------------------+|
|  |                                                          ||
|  |  [テキストエリア]                                        ||
|  |                                                          ||
|  +----------------------------------------------------------+|
|                                                              |
|  [下書き保存]                           [提出する]          |
+--------------------------------------------------------------+
```

### 5-3. 入力項目

**訪問記録（1行ごと・複数行追加可）**

| 項目名 | 型 | 必須 | バリデーション |
|--------|----|------|----------------|
| 顧客名 | セレクトボックス（顧客マスタから選択） | ○ | 選択必須 |
| 訪問内容 | テキストエリア | ○ | 最大1000文字 |
| 訪問時刻 | 時刻入力 | − | HH:MM形式 |

**日報本文**

| 項目名 | 型 | 必須 | バリデーション |
|--------|----|------|----------------|
| 課題・相談（Problem） | テキストエリア | − | 最大2000文字 |
| 明日やること（Plan） | テキストエリア | − | 最大2000文字 |

### 5-4. アクション

| ボタン | 処理 | ステータス |
|--------|------|------------|
| 訪問記録を追加 | 訪問記録行を1行追加 | − |
| 行削除（各行） | 対象行を削除（1行以上を維持） | − |
| 下書き保存 | `status = 下書き` で保存 | 下書き |
| 提出する | `status = 提出済` で保存 | 提出済 |

### 5-5. バリデーション・制御

- 訪問記録が0件の場合は「提出する」を非活性にする
- 提出後は編集不可とする（ステータスが「提出済」「確認済」）
- 訪問記録の表示順は `order` カラムで管理し、ドラッグ&ドロップで並び替え可

## 6. 日報詳細画面 `REPORT-DETAIL`

### 6-1. 概要

日報の内容を参照する画面。上長はコメントを入力・投稿できる。営業担当者はコメントを閲覧のみ。

### 6-2. 画面レイアウト

```
+--------------------------------------------------------------+
|  [グローバルナビ]                                            |
+--------------------------------------------------------------+
|  日報詳細  田中 太郎 / 2024年11月20日   [ステータス: 提出済] |
|                                                              |
|  ■ 訪問記録                                                 |
|  +----------------------------------------------------------+|
|  |  #  | 顧客名    | 訪問内容               | 訪問時刻      ||
|  |-----|-----------|------------------------|---------------||
|  |  1  | 株式会社A | ○○の提案をした        | 10:00         ||
|  |  2  | 株式会社B | 課題ヒアリング実施     | 14:00         ||
|  +----------------------------------------------------------+|
|                                                              |
|  ■ 課題・相談（Problem）                                    |
|  +----------------------------------------------------------+|
|  |  株式会社Aの担当者が異動予定。次回フォロー要。           ||
|  +----------------------------------------------------------+|
|                                                              |
|  ■ 明日やること（Plan）                                     |
|  +----------------------------------------------------------+|
|  |  株式会社Cへの提案資料を作成する。                       ||
|  +----------------------------------------------------------+|
|                                                              |
|  ■ 上長コメント                                             |
|  +----------------------------------------------------------+|
|  |  山田 部長  2024/11/20 20:00                             ||
|  |  株式会社Aの件、よく対応できました。引き続き注力を。     ||
|  +----------------------------------------------------------+|
|                                                              |
|  ※上長のみ表示                                             |
|  +----------------------------------------------------------+|
|  |  コメントを入力…                                        ||
|  |                                                          ||
|  +----------------------------------------------------------+|
|                         [コメントを投稿する] [確認済にする] ||
+--------------------------------------------------------------+
```

### 6-3. 表示項目

| 項目名 | 説明 |
|--------|------|
| 対象者・日付 | 日報の営業担当者名と対象日 |
| ステータス | 現在のステータスをバッジ表示 |
| 訪問記録 | 訪問した顧客と内容の一覧 |
| 課題・相談 | Problem の内容 |
| 明日やること | Plan の内容 |
| 上長コメント | コメント投稿者・日時・内容 |

### 6-4. アクション

| ボタン | 処理 | 表示条件 |
|--------|------|----------|
| コメントを投稿する | コメントを保存して表示 | 上長のみ |
| 確認済にする | `status = 確認済` に更新 | 上長のみ・ステータスが「提出済」 |
| 編集へ戻る | REPORT-EDIT へ遷移 | 営業本人・ステータスが「下書き」のみ |

## 7. 日報一覧画面（上長） `MGR-REPORT-LIST`

### 7-1. 概要

上長が部下全員の日報を一覧で確認する画面。ステータス・担当者・日付で絞り込み可能。

### 7-2. 画面レイアウト

```
+--------------------------------------------------------------+
|  [グローバルナビ]                                            |
+--------------------------------------------------------------+
|  部下の日報一覧                                              |
|                                                              |
|  [担当者 ▼]  [ステータス ▼]  [年月 ▼]  [検索]            |
+--------------------------------------------------------------+
|  日付       | 担当者   | ステータス | 訪問件数 |            |
|-------------|----------|------------|----------|------------|
|  2024/11/20 | 田中 太郎 | 提出済    | 3件      | [確認する] |
|  2024/11/20 | 鈴木 花子 | 確認済    | 2件      | [表示]    |
|  2024/11/19 | 田中 太郎 | 確認済    | 4件      | [表示]    |
+--------------------------------------------------------------+
```

### 7-3. 絞り込み条件

| 項目名 | 型 | 説明 |
|--------|----|------|
| 担当者 | セレクトボックス | 部下の営業担当者から選択（全員デフォルト） |
| ステータス | セレクトボックス | 下書き / 提出済 / 確認済 / 全て |
| 年月 | 月選択 | 表示する年月を指定 |

### 7-4. アクション

| ボタン | 処理 | 表示条件 |
|--------|------|----------|
| 確認する | REPORT-DETAIL へ遷移 | ステータスが「提出済」 |
| 表示 | REPORT-DETAIL へ遷移 | ステータスが「確認済」 |

## 8. 顧客マスタ一覧画面 `CUSTOMER-LIST`

### 8-1. 概要

顧客マスタの一覧表示・検索画面。管理者は登録・編集も可能。

### 8-2. 画面レイアウト

```
+--------------------------------------------------------------+
|  [グローバルナビ]                                            |
+--------------------------------------------------------------+
|  顧客マスタ                      [＋ 新規顧客を登録]        |
|                                                              |
|  キーワード: [            ]  業種: [▼]  [検索]            |
+--------------------------------------------------------------+
|  顧客名           | 業種     | 電話番号     |               |
|-------------------|----------|--------------|---------------|
|  株式会社A        | 製造業   | 03-0000-0001 | [編集][削除]  |
|  株式会社B        | IT       | 03-0000-0002 | [編集][削除]  |
+--------------------------------------------------------------+
```

### 8-3. 表示項目

| 項目名 | 説明 |
|--------|------|
| 顧客名 | customers.name |
| 業種 | customers.industry |
| 電話番号 | customers.phone |

### 8-4. アクション

| ボタン | 処理 | 表示条件 |
|--------|------|----------|
| 新規顧客を登録 | CUSTOMER-EDIT（新規）へ遷移 | 管理者のみ |
| 編集 | CUSTOMER-EDIT（編集）へ遷移 | 管理者のみ |
| 削除 | 確認ダイアログ後に論理削除 | 管理者のみ |

## 9. 顧客マスタ登録・編集画面 `CUSTOMER-EDIT`

### 9-1. 概要

顧客情報の新規登録・編集画面。管理者のみアクセス可能。

### 9-2. 入力項目

| 項目名 | 型 | 必須 | バリデーション |
|--------|----|------|----------------|
| 顧客名 | テキスト | ○ | 最大100文字 |
| 住所 | テキスト | − | 最大200文字 |
| 電話番号 | テキスト | − | 電話番号形式 |
| 業種 | セレクトボックス | − | マスタより選択 |

### 9-3. アクション

| ボタン | 処理 | 遷移先 |
|--------|------|--------|
| 保存 | バリデーション後に登録・更新 | CUSTOMER-LIST |
| キャンセル | 変更破棄 | CUSTOMER-LIST |

### 10-2. 画面レイアウト

```
+--------------------------------------------------------------+
|  [グローバルナビ]                                            |
+--------------------------------------------------------------+
|  営業マスタ                      [＋ 新規担当者を登録]      |

+--------------------------------------------------------------+
```

### 10-3. 表示項目

| 項目名 | 説明 |
|--------|------|

| メールアドレス | salespeople.email |

## 11. 営業マスタ登録・編集画面 `SALESPERSON-EDIT`

### 11-1. 概要

営業担当者情報の新規登録・編集画面。管理者のみアクセス可能。

### 11-2. 入力項目

| 項目名 | 型 | 必須 | バリデーション |
|--------|----|------|----------------|
| 氏名 | テキスト | ○ | 最大50文字 |
| メールアドレス | テキスト | ○ | メール形式・一意 |
| パスワード | パスワード | ○（新規のみ） | 8文字以上 |
| ロール | セレクトボックス | ○ | 営業 / 上長 / 管理者 |
| 上長 | セレクトボックス | − | ロールが「上長」「管理者」の担当者から選択 |

### 11-3. アクション

| ボタン | 処理 | 遷移先 |
|--------|------|--------|
| 保存 | バリデーション後に登録・更新 | SALESPERSON-LIST |
| キャンセル | 変更破棄 | SALESPERSON-LIST |
