## 1. バリデーション実施タイミング

| タイミング | 説明 | 対象 |
|------------|------|------|
| フォーカスアウト時 | 入力フィールドからフォーカスが外れた際に単項目チェックを実行 | 必須・形式チェック |
| ボタン押下時 | 保存・提出・投稿ボタン押下時に全項目を一括チェック | 全チェック |
| リアルタイム | 文字入力中に文字数カウントを表示（残り文字数として表示） | 文字数チェック |

## 2. エラー表示仕様

### 2-1. フィールドエラー（インライン）

単項目のバリデーションエラーは、対象フィールドの直下に赤字で表示する。

```
[入力フィールド（赤枠）          ]
⚠ メールアドレスの形式が正しくありません
```

### 2-2. フォームエラー（サマリー）

ボタン押下時に複数のエラーがある場合は、フォーム上部にまとめて表示する。

```
+--------------------------------------------------+
| ✕  入力内容にエラーがあります。                  |
|    ・顧客名を選択してください（1行目）            |
|    ・訪問内容を入力してください（2行目）          |
+--------------------------------------------------+
```

### 2-3. トースト通知

処理結果（成功・失敗）はトーストで画面右上に表示する。3秒後に自動消去。

| 種別 | 色 | 表示秒数 |
|------|----|---------:|
| 成功 | 緑 | 3秒 |
| 業務エラー | 黄 | 5秒 |
| システムエラー | 赤 | 手動で閉じるまで |

## 3. バリデーション一覧

### 3-1. ログイン画面 `LOGIN`

| # | 項目名 | チェック種別 | 条件 | タイミング |
|---|--------|-------------|------|-----------|
| L-01 | メールアドレス | 必須 | 未入力の場合エラー | フォーカスアウト・ボタン押下 |
| L-02 | メールアドレス | 形式 | RFC 5322 準拠のメール形式でない場合エラー | フォーカスアウト・ボタン押下 |
| L-03 | パスワード | 必須 | 未入力の場合エラー | フォーカスアウト・ボタン押下 |
| L-04 | パスワード | 最小文字数 | 8文字未満の場合エラー | フォーカスアウト・ボタン押下 |
| L-05 | （認証） | 業務 | メールアドレスとパスワードの組み合わせが一致しない場合エラー | ボタン押下後（サーバー） |

### 3-2. 日報作成・編集画面 `REPORT-EDIT`

#### 訪問記録（各行に適用）

| # | 項目名 | チェック種別 | 条件 | タイミング |
|---|--------|-------------|------|-----------|
| RE-01 | 顧客名 | 必須 | 未選択の場合エラー | フォーカスアウト・ボタン押下 |
| RE-02 | 訪問内容 | 必須 | 未入力の場合エラー | フォーカスアウト・ボタン押下 |
| RE-03 | 訪問内容 | 最大文字数 | 1,000文字を超える場合エラー | リアルタイム・ボタン押下 |
| RE-04 | 訪問時刻 | 形式 | HH:MM 形式でない場合エラー（任意入力）| フォーカスアウト・ボタン押下 |
| RE-05 | 訪問時刻 | 範囲 | 00:00〜23:59 の範囲外の場合エラー | フォーカスアウト・ボタン押下 |

#### 訪問記録（全体）

| # | 項目名 | チェック種別 | 条件 | タイミング |
|---|--------|-------------|------|-----------|
| RE-06 | 訪問記録 | 最低件数（提出時のみ） | 1件も登録されていない場合「提出する」ボタンを非活性にする | リアルタイム |

#### 日報本文

| # | 項目名 | チェック種別 | 条件 | タイミング |
|---|--------|-------------|------|-----------|
| RE-07 | 課題・相談（Problem） | 最大文字数 | 2,000文字を超える場合エラー | リアルタイム・ボタン押下 |
| RE-08 | 明日やること（Plan） | 最大文字数 | 2,000文字を超える場合エラー | リアルタイム・ボタン押下 |

#### 業務ルール

| # | チェック種別 | 条件 | タイミング |
|---|-------------|------|-----------|
| RE-09 | 重複チェック | 同一営業・同一日付の日報がすでに存在する場合エラー | ボタン押下後（サーバー） |
| RE-10 | 権限チェック | 提出済・確認済の日報を編集しようとした場合エラー | 画面表示時（サーバー） |
| RE-11 | 他者日報チェック | ログインユーザー以外の日報を編集しようとした場合エラー | 画面表示時（サーバー） |

### 3-3. 日報詳細画面 コメント `REPORT-DETAIL`

| # | 項目名 | チェック種別 | 条件 | タイミング |
|---|--------|-------------|------|-----------|
| RD-01 | コメント | 必須 | 未入力の状態で「コメントを投稿する」を押下した場合エラー | ボタン押下 |
| RD-02 | コメント | 最大文字数 | 1,000文字を超える場合エラー | リアルタイム・ボタン押下 |
| RD-03 | （権限） | 権限チェック | 上長以外がコメント投稿APIを呼び出した場合エラー | ボタン押下後（サーバー） |
| RD-04 | （権限） | 権限チェック | 上長以外が「確認済にする」APIを呼び出した場合エラー | ボタン押下後（サーバー） |
| RD-05 | （ステータス） | 業務 | すでに「確認済」の日報に対して「確認済にする」を実行した場合エラー | ボタン押下後（サーバー） |

## 4. エラーメッセージ一覧

### 4-1. フィールドエラー（インライン）

フィールド直下に表示するメッセージ。`{項目名}` は実際の項目名に置換する。

| エラーコード | 表示メッセージ |
|-------------|---------------|
| L-01 | メールアドレスを入力してください |
| L-02 | メールアドレスの形式が正しくありません |
| L-03 | パスワードを入力してください |
| L-04 | パスワードは8文字以上で入力してください |
| RE-01 | 顧客を選択してください |
| RE-02 | 訪問内容を入力してください |
| RE-03 | 訪問内容は1,000文字以内で入力してください（現在 {n} 文字） |
| RE-04 | 訪問時刻はHH:MM形式で入力してください |
| RE-05 | 訪問時刻は00:00〜23:59の範囲で入力してください |
| RE-07 | 課題・相談は2,000文字以内で入力してください（現在 {n} 文字） |
| RE-08 | 明日やることは2,000文字以内で入力してください（現在 {n} 文字） |
| RD-01 | コメントを入力してください |
| RD-02 | コメントは1,000文字以内で入力してください（現在 {n} 文字） |
| CE-01 | 顧客名を入力してください |
| CE-02 | 顧客名は100文字以内で入力してください（現在 {n} 文字） |
| CE-03 | 住所は200文字以内で入力してください（現在 {n} 文字） |
| CE-04 | 電話番号は数字とハイフンのみで入力してください |
| CE-05 | 電話番号は20文字以内で入力してください |
| SE-01 | 氏名を入力してください |
| SE-02 | 氏名は50文字以内で入力してください（現在 {n} 文字） |
| SE-03 | メールアドレスを入力してください |
| SE-04 | メールアドレスの形式が正しくありません |
| SE-06 | パスワードを入力してください |
| SE-07 | パスワードは8文字以上で入力してください |
| SE-08 | パスワードには英字と数字をそれぞれ1文字以上含めてください |
| SE-09 | ロールを選択してください |

---

### 4-2. フォームエラー（サマリー）

ボタン押下時に複数エラーがある場合のフォーム上部まとめ表示。

| 条件 | 表示メッセージ |
|------|---------------|
| 1件以上のエラーがある場合 | 入力内容にエラーがあります。各項目のエラーをご確認ください |
| 訪問記録が0件で提出しようとした場合 | 訪問記録を1件以上入力してから提出してください |

---

### 4-3. システムエラー（トースト・赤）

サーバーエラーや予期しない障害時に表示する。

| エラーコード | 表示メッセージ | 補足 |
|-------------|---------------|------|
| SYS-001 | 通信エラーが発生しました。時間をおいて再度お試しください | ネットワーク障害 / タイムアウト |
| SYS-002 | サーバーエラーが発生しました。管理者にお問い合わせください | HTTP 500系 |
| SYS-003 | セッションが切れました。再度ログインしてください | 認証トークン期限切れ |
| SYS-004 | この操作を行う権限がありません | HTTP 403 |
| SYS-005 | 対象データが見つかりません | HTTP 404 |

---

### 4-4. 業務エラー（トースト・黄）

業務ルール違反により処理が行えない場合に表示する。

| エラーコード | 表示メッセージ | 該当バリデーション |
|-------------|---------------|-------------------|
| BIZ-001 | メールアドレスまたはパスワードが正しくありません | L-05 |
| BIZ-002 | 同じ日付の日報がすでに存在します | RE-09 |
| BIZ-003 | 提出済みまたは確認済みの日報は編集できません | RE-10 |
| BIZ-004 | 他の担当者の日報は編集できません | RE-11 |
| BIZ-005 | すでに確認済みの日報です | RD-05 |
| BIZ-006 | このメールアドレスはすでに登録されています | SE-05 |
| BIZ-007 | 自分自身を上長に設定することはできません | SE-10 |
| BIZ-008 | この顧客は訪問記録に使用されているため削除できません | CE-07 |
| BIZ-009 | この担当者は日報またはコメントが存在するため削除できません | SE-11 |

---

### 4-5. 確認ダイアログ

削除や重複登録など、ユーザーへの確認が必要な操作に使用する。

| 操作 | タイトル | 本文 | ボタン |
|------|----------|------|--------|
| 顧客削除 | 顧客を削除しますか？ | 「{顧客名}」を削除します。この操作は取り消せません。 | 削除する／キャンセル |
| 担当者削除 | 担当者を削除しますか？ | 「{氏名}」を削除します。この操作は取り消せません。 | 削除する／キャンセル |
| 顧客名重複 | 同名の顧客が存在します | 「{顧客名}」はすでに登録されています。続けて登録しますか？ | 登録する／キャンセル |
| 編集内容破棄 | 編集内容を破棄しますか？ | 保存されていない変更は失われます。 | 破棄する／キャンセル |
